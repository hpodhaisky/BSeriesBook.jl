Reference

The functions are grouped by the chapters of the book.

BSeriesBook.BSeriesBook — Module
BSeriesBook

Julia companion to J. C. Butcher, B-Series: Algebraic Analysis of Numerical Methods, Springer Series in Computational Mathematics 55 (2nd edition in preparation).

The package follows the book's notation and algorithms: trees are identified by their standard number (Algorithm 3), B-series are vectors over this numbering. It is software for teaching and research; in addition to the B-series of Runge–Kutta methods it provides the underlying one-step method of general linear methods (Chapter 6).

For B-series in Julia see also BSeries.jl and RootedTrees.jl (H. Ranocha, D. I. Ketcheson), which the test suite uses as an independent reference.

TreeTable

All trees up to order p_max in the standard numbering, as generated by Algorithm 3 of the book: order[n], first[p], last[p], L[n], R[n], prod[ℓ, r]. L[1] and R[1] are 0, since τ has no factors.

BSeriesBook.Splitting — Type
Splitting

One splitting of a tree t: (k, F, m) stands for the subtree t' = t_k containing the root, the forest t ∖ t' = F (sorted standard numbers) and the number m of ways in which this pair arises.

source
BSeriesBook.splittings — Function
splittings(T) -> Vector{Vector{Splitting}}

For every tree tn all pairs (t', t ∖ t'), where t' ≤ tn is a subtree containing the root and t ∖ t' the forest of the removed parts, with multiplicities. The table does not depend on any B-series; it is built once per Trees object (on first use) by the β-product recursion: for tn = ti ∘ t_j,

  • the edge to tj is cut: (tk, F) of ti gives (tk, F ∪ {t_j});
  • it is kept: (tk, F) of ti and (tℓ, G) of tj give (tk ∘ tℓ, F ∪ G).

The pair (t, ∅) is included, the pair (∅, {t}) is not.

Book: Section 2.8 (subtrees), used for the composition (Theorem 3.9).

BSeriesBook.lambda_matrix — Function
lambda_matrix(T, a, p_top) -> Matrix

The coefficients of λ(a, t) = Σ{t' ≤ t} a(t ∖ t') t' (sum over the subtrees t' of t that contain the root) for all trees of order ≤ `ptop:λ[n, k]` is the coefficient of tk in λ(a, tn).

BSeriesBook.lambda_hat — Function
lambda_hat(T, a, p_top) -> Vector{Vector}

The efficient representation λ̂ of λ: λ̂[n] holds the coefficients of λ(a, tn) for the trees of order less than |tn| (the coefficient of t_n itself is 1, and no other tree of the same order occurs).

Book: Section 3.9, Algorithm 6 ("Evaluate λ", efficient form) and the list printed after it.

source
BSeriesBook.compose — Function
compose(a, b, T; b0 = 1) -> Vector

The product ab of two B-series (first a, then b): (ab)(t) = b(∅) a(t) + Σ_{∅ < t' ≤ t} a(t ∖ t') b(t'), for a with a(∅) = 1, where a(F) is the product of a over the trees of the forest F. Uses the table of splittings.

Book: Section 3.9 (composition of B-series).

source
BSeriesBook.inverse — Function
inverse(a, T) -> Vector

The inverse a⁻¹ in the B-group, from a⁻¹(t) = -a(t) - Σ_{∅ < t' < t} a(t ∖ t') a⁻¹(t').

Book: Section 3.9 ("Inverse of B-series").

Chapter 3: substitution and modified equations

BSeriesBook.Partition — Type
Partition

One partition of a tree t into subtrees, obtained by cutting a set of edges: (k, F, s, m) stands for the piece tk containing the root of t, the other pieces F (sorted standard numbers), the skeleton ts (each piece contracted to a vertex) and the number m of edge sets giving this triple.

source
BSeriesBook.tree_partitions — Function
tree_partitions(T) -> Vector{Vector{Partition}}

For every tree tn all partitions (k, F, s, m): root piece tk, other pieces F, skeleton ts, multiplicity m. Built once per Trees object by the β-product recursion: for tn = ti ∘ tj combine every partition (k, F, s) of ti with every partition (ℓ, G, u) of tj;

  • the edge to tj is cut: root piece tk, pieces F ∪ G ∪ {tℓ}, skeleton ts ∘ t_u;
  • it is kept: root piece tk ∘ tℓ, pieces F ∪ G, skeleton ts × tu (roots identified, join_roots).

Summed over F, the multiplicities of tn add up to 2^(|tn| - 1).

source
BSeriesBook.join_roots — Function
join_roots(T, s, u)

The tree obtained from ts and tu by identifying their roots, [B⁻(t_s) B⁻(t_u)] (Butcher's product t × t′).

source
BSeriesBook.substitute — Function
substitute(b, a, T) -> Vector

The substitution b ⋆ a of the B-series b of a vector field (b(∅) = 0, not stored) into the B-series a: (b ⋆ a)(t) = Σ_partitions b(pieces) a(skeleton). (b ⋆ a)(∅) = a(∅). Same argument order as BSeries.substitute.

Book: Section 3.9; Chartier–Hairer–Vilmart (2010), Section 3.2.

source
BSeriesBook.modified_equation — Function
modified_equation(a, T) -> Vector

The B-series b of the modified vector field of a method with B-series a: the exact flow of y′ = h⁻¹ Bh(b)(y) is the method, b ⋆ E = a. Solved tree by tree (in standard order) from b(t) = a(t) − Σ{partitions other than {t}} b(pieces) E(skeleton), the partition {t} (no edge cut, skeleton τ) being the only one in which b(t) occurs. For a method of order p, b(t) = 0 for 1 < |t| ≤ p.

Book: backward error analysis (not in the 1st edition); Hairer, Lubich, Wanner, Geometric Numerical Integration, Chapter IX.

source
modified_equation(rk::RungeKuttaMethod, T)

The modified vector field of the Runge–Kutta method rk.

source
BSeriesBook.modifying_integrator — Function
modifying_integrator(a, T) -> Vector

The B-series b of the vector field to which the method with B-series a must be applied to give the exact flow: b ⋆ a = E. Solved tree by tree from b(t) a(τ) = E(t) − Σ_{other partitions} b(pieces) a(skeleton).

Chapter 6: general linear methods

BSeriesBook.conjugacy_step — Function
conjugacy_step(a, b, T, p) -> (true, x a x⁻¹, x) or (false,)

Decide whether central B-series a and b with a = b + Op are conjugate to order p, i.e. whether there is x, differing from the identity only on the trees of order p − 1, with x a x⁻¹ = b + O{p+1}.

The values x(t), |t| = p − 1, are found from the conditions (xa)(t ∘ τ) = (bx)(t ∘ τ). These form a linear system, which is coupled whenever a tree t ∘ τ can lose a leaf in more than one way; it is solved exactly. Then the conditions for all trees of order p are tested.

Book: Section 6.6, Algorithm 7 (corrected for the 2nd edition: the 1st edition computes each x(t) from t ∘ τ alone, which fails from p = 4).

source
BSeriesBook.conjugate_order — Function
conjugate_order(a, b, T) -> p

The largest p ≤ pmax such that a is conjugate to b to order p, i.e. x a x⁻¹ = b + O{p+1} for some x, found by repeated use of Algorithm 7 of the book, conjugacy_step (one order at a time, free parameters set to 0). For a = Ẽ, the underlying one-step method of a general linear method, and b = E, this is the order of the method (with a suitable starting method).

The test is exact: use rational (or other exact) coefficients.

Book: Section 6.6 ("Test for conjugacy").

BSeriesBook.is_partitioned_form — Function
is_partitioned_form(glm) -> Bool

Whether glm has the partitioned form (6.6 a) of the book: U = [𝟏 Û], B = [bᵀ; B̂], V = [1 0ᵀ; 0 V̂], with 1 not an eigenvalue of V̂.

source
BSeriesBook.partitioned_form — Function
partitioned_form(glm) -> (glm′, Q)

An equivalent method in the partitioned form (6.6 a), with inputs ỹ = Q⁻¹ y: A′ = A, U′ = U Q, B′ = Q⁻¹ B, V′ = Q⁻¹ V Q. The first column of Q is the preconsistency vector u (V u = u, U u = 𝟏); the others span the range of V - I, the invariant subspace for the other eigenvalues of V. The first component of ỹ is wᵀ y, w the left eigenvector of V for the eigenvalue 1 with wᵀu = 1. Requires 1 to be a simple eigenvalue of V.

Book: Section 6.6, (6.6 a).

source
BSeriesBook.underlying_one_step — Function
underlying_one_step(glm, T) -> (; E, ξ, η, ηD, ζ)

The underlying one-step method of glm and the starting method that goes with it, to the order of T:

  • E[n] = Ẽ(t_n), the B-series of the underlying one-step method (Ẽ(∅) = 1, not stored);
  • ξ[n] = ξ(t_n) ∈ ℝ^{r-1}, the non-principal part of the starting method of the partitioned form (ξ(∅) = 0);
  • η[n], ηD[n] ∈ ℝ^s, the stages and stage derivatives;
  • ζ[n] ∈ ℝ^r, the starting method in the original input basis, ζ(∅) = u, ζ(t) = Q [0; ξ(t)]: its principal part wᵀζ is the identity.

A method that is not in the partitioned form (6.6 a) is first transformed with partitioned_form.

Book: Section 6.6, recursion (6.6 d) and Table 18.

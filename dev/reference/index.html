Reference

The functions are grouped by the chapters of the book.

BSeriesBook.BSeriesBook — Module
BSeriesBook

Julia companion to J. C. Butcher, B-Series: Algebraic Analysis of Numerical Methods, Springer Series in Computational Mathematics 55 (2nd edition in preparation).

The package follows the book's notation and algorithms: trees are identified by their standard number (Algorithm 3), and B-series are vectors over this numbering whose type records a(∅): GeneralBSeries (𝖡*), CentralBSeries (𝖡, a(∅) = 1) and VectorFieldBSeries (𝖡⁰, a(∅) = 0). It is software for teaching and research; in addition to the B-series of Runge–Kutta methods it provides the underlying one-step method of general linear methods (Chapter 6).

For B-series in Julia see also BSeries.jl and RootedTrees.jl (H. Ranocha, D. I. Ketcheson), which the test suite uses as an independent reference.

Chapter 2: trees

BSeriesBook.Trees — Type
Trees(p_max) -> Trees

Generate all rooted trees up to order p_max in the standard numbering, together with their tree functions (order, symmetry, factorial, ...). The result T is a collection of Trees: length(T) is the number of trees, T[n] is the tree with standard number n, and iterating over T gives all trees in standard order.

julia> T = Trees(4)
Trees: 8 trees up to order 4

julia> T[4]
t4 = [[τ]]
source
BSeriesBook.Tree — Type
Tree(T::Trees, n::Integer) -> Tree

The rooted tree t_n: a wrapper around the standard number n, together with the table T in which its tree functions are looked up. number returns the wrapped integer n.

A Tree is usually obtained as T[n] (the same as Tree(T, n)), by iterating over T, or from other trees (children, beta_product, bplus). Functions on trees (order, symmetry, ...) take a Tree. Two trees are equal if they have the same standard number (the numbering does not depend on the maximal order). A B-series a is indexed by trees, a[t] = a(t).

julia> T = Trees(4);

julia> t = T[4]
t4 = [[τ]]

julia> number(t), order(t)
(4, 3)

BSeriesBook.Forest — Type
Forest(trees::AbstractVector{Tree}) -> Forest
Forest()

A forest: a multiset of trees, stored as the vector of its trees sorted by standard number. Forest() is the empty forest. A Forest is an AbstractVector{Tree}: length(F) is the number of trees, F[i] the i-th tree, and iterating over F gives the trees with repetitions. Two forests are equal if they contain the same trees. It is shown as a monomial in its trees, e.g. τ²[τ], and ∅ when empty.

Forests arise as B⁻(t) (children), as the removed parts t ∖ t' of a Splitting and as the pieces of a Partition. Book: Section 2.1.

julia> T = Trees(4);

julia> F = children(T[6])
τ[τ]

julia> order(F), length(F), F[2]
(3, 2, t2 = [τ])

julia> Forest()
∅

BSeriesBook.Splitting — Type
Splitting

One splitting (t', t ∖ t') of a tree t, with the fields

  • subtree::Tree: the subtree t' ≤ t containing the root of t;
  • forest::Forest: the forest t ∖ t' of the removed parts;
  • multiplicity::Int: the number of subtrees t' of t (sets of vertices) giving this pair.

Returned by splittings. Book: Section 2.8.

source
BSeriesBook.splittings — Function
splittings(t::Tree) -> Vector{Splitting}

All splittings (t', t ∖ t') of t: t' ≤ t is a subtree containing the root and t ∖ t' the forest of the removed parts, with multiplicities. The pair (t, ∅) is included, the pair (∅, t) is not. Summed over t', the multiplicities give the number of subtrees of t containing the root.

The splittings of all trees are computed once per Trees object (on first use) by the β-product recursion: for tn = ti ∘ t_j,

  • the edge to tj is cut: (tk, F) of ti gives (tk, F t_j);
  • it is kept: (tk, F) of ti and (tℓ, G) of tj give (tk ∘ tℓ, F G).

Book: Section 2.8 (subtrees), used for the composition (Theorem 3.9).

julia> T = Trees(4);

julia> splittings(T[4])
3-element Vector{Splitting}:
 Splitting(t' = τ, t ∖ t' = [τ], multiplicity 1)
 Splitting(t' = [τ], t ∖ t' = τ, multiplicity 1)
 Splitting(t' = [[τ]], t ∖ t' = ∅, multiplicity 1)

Chapter 3: B-series

BSeriesBook.AbstractBSeries — Type
AbstractBSeries{S} <: AbstractVector{S}

A B-series a: T# → S, truncated at the order of its Trees. As a vector, a[n] = a(tₙ) over the standard numbering; the value on the empty tree is a[∅]. Subtypes: GeneralBSeries (𝖡*), CentralBSeries (𝖡, a(∅) = 1) and VectorFieldBSeries (𝖡⁰, a(∅) = 0).

Indexing with a range, broadcasting and other generic vector operations act on the coefficients a(tₙ) and return plain vectors; +, -, scalar multiplication, == and ≈ take a(∅) into account and return B-series.

Book: Section 3.4.

A B-series in 𝖡* with a(∅) = a0 and a(tₙ) = coef[n] (or a(t) = f(t) for every Tree t). Book: Section 3.4.

BSeriesBook.CentralBSeries — Type
CentralBSeries(T, coef)
CentralBSeries(f, T)
CentralBSeries(a::AbstractBSeries)

A central B-series, an element of the B-group 𝖡: a(∅) = 1 (not stored) and a(tₙ) = coef[n] (or a(t) = f(t) for every Tree t). The B-series of a one-step method. Converting another B-series checks that a(∅) = 1; CentralBSeries{S}(a) changes the number type to S.

Book: Section 3.4 ("central series").

A B-series in 𝖡⁰: a(∅) = 0 (not stored) and a(tₙ) = coef[n] (or a(t) = f(t) for every Tree t). h⁻¹ B_h(a) is a vector field, for example a modified equation; the difference of two central B-series lies in 𝖡⁰. Converting another B-series checks that a(∅) = 0.

BSeriesBook.slope — Function
slope(y::CentralBSeries, gamma = 0) -> VectorFieldBSeries

The B-series of hf(w), where w = y + γ hf(w) (as B-series about y₀): returns dw = wD with w = y + γ dw, from dw(τ) = 1, dw(tₙ) = dw(t{L[n]}) w(t{R[n]}), w(tₙ) = y(tₙ) + γ dw(tₙ), in one loop over the standard numbering, without iteration.

slope(y) (γ = 0) is yD, the series of hf(Bh(y)y₀); `slope(identityseries(T))` is D itself. With y = id and γ = 1, w is the implicit Euler method.

Book: Section 3.5 (the map slope, D ∈ 𝖡⁰, Theorem on aD).

source
BSeriesBook.lambda_matrix — Function
lambda_matrix(a::CentralBSeries, p_top = p_max) -> Matrix

The coefficients of λ(a, t) = Σ{t' ≤ t} a(t ∖ t') t' (sum over the subtrees t' of t that contain the root) for all trees of order ≤ `ptop:λ[n, k]` is the coefficient of tk in λ(a, tn), so that (ab)(tₙ) = b(∅) a(tₙ) + Σk λ[n, k] b(tk).

Book: Section 3.9, Algorithm 5 ("Evaluate λ"), using λ(a, t₁ ∘ t₂) = a(t₂) λ(a, t₁) + λ(a, t₁) ∘ λ(a, t₂).

BSeriesBook.compose — Function
compose(a::CentralBSeries, b::AbstractBSeries), a * b

The product ab of the book (first a, then b), 𝖡 × 𝖡* → 𝖡*: (ab)(∅) = b(∅), (ab)(t) = b(∅) a(t) + Σ{∅ < t' ≤ t} a(t ∖ t') b(t'), where a(F) is the product of a over the trees of the forest F. The result has the type of b: it is central if b is central and in 𝖡⁰ if b is. The first factor must be central, otherwise Bh(b) ∘ B_h(a) is not a B-series. Uses the table of splittings.

Book: Section 3.9 (composition of B-series).

BSeriesBook.Partition — Type
Partition

One partition of a tree t into pieces, obtained by cutting a set of edges, with the fields

  • root_piece::Tree: the piece containing the root of t;
  • pieces::Forest: the other pieces;
  • skeleton::Tree: t with every piece contracted to a vertex;
  • multiplicity::Int: the number of edge sets giving this triple.

Returned by tree_partitions. Book: Section 3.9.

source
BSeriesBook.tree_partitions — Function
tree_partitions(t::Tree) -> Vector{Partition}

All partitions of t into pieces, obtained by cutting a set of edges: root piece, other pieces, skeleton and multiplicity. The multiplicities add up to 2^(|t| - 1), the number of edge sets.

The partitions of all trees are computed once per Trees object (on first use) by the β-product recursion: for tn = ti ∘ tj combine every partition (tk, F, ts) of ti with every partition (tℓ, G, tu) of t_j;

  • the edge to tj is cut: root piece tk, pieces F G tℓ, skeleton ts ∘ t_u;
  • it is kept: root piece tk ∘ tℓ, pieces F G, skeleton ts × tu (roots identified, join_roots).
julia> T = Trees(4);

julia> tree_partitions(T[4])
4-element Vector{Partition}:
 Partition(root piece τ, pieces τ², skeleton [[τ]], multiplicity 1)
 Partition(root piece τ, pieces [τ], skeleton [τ], multiplicity 1)
 Partition(root piece [τ], pieces τ, skeleton [τ], multiplicity 1)
 Partition(root piece [[τ]], pieces ∅, skeleton τ, multiplicity 1)

BSeriesBook.substitute — Function
substitute(b::VectorFieldBSeries, a::AbstractBSeries)

The substitution b ⋆ a of the B-series b ∈ 𝖡⁰ of a vector field into the B-series a: the method a applied to the vector field h⁻¹ Bh(b), (b ⋆ a)(∅) = a(∅), (b ⋆ a)(t) = Σpartitions b(pieces) a(skeleton). The result has the type of a. Same argument order as BSeries.substitute.

BSeriesBook.modified_equation — Function
modified_equation(a::CentralBSeries) -> VectorFieldBSeries

The B-series b of the modified vector field of a method with B-series a: the exact flow of y′ = h⁻¹ Bh(b)(y) is the method, b ⋆ E = a. Solved tree by tree (in standard order) from b(t) = a(t) − Σ{partitions other than {t}} b(pieces) E(skeleton), the partition {t} (no edge cut, skeleton τ) being the only one in which b(t) occurs. For a method of order p, b(t) = 0 for 1 < |t| ≤ p.

Book: backward error analysis (not in the 1st edition); Hairer, Lubich, Wanner, Geometric Numerical Integration, Chapter IX.

Chapter 6: general linear methods

BSeriesBook.conjugacy_step — Function
conjugacy_step(a::CentralBSeries, b::CentralBSeries, p) -> (; x, conjugated) or nothing

Decide whether central B-series a and b with a = b + Op are conjugate to order p, i.e. whether there is x, differing from the identity only on the trees of order p − 1, with x a x⁻¹ = b + O{p+1}. If so, return x and conjugated = x a x⁻¹ (which agrees with b for |t| ≤ p); otherwise nothing.

The values x(t), |t| = p − 1, are found from the conditions (xa)(t ∘ τ) = (bx)(t ∘ τ). These form a linear system, which is coupled whenever a tree t ∘ τ can lose a leaf in more than one way; it is solved exactly. Then the conditions for all trees of order p are tested.

Book: Section 6.6, Algorithm 7.

source
BSeriesBook.conjugate_order — Function
conjugate_order(a::CentralBSeries, b::CentralBSeries) -> p

The largest p ≤ pmax such that a is conjugate to b to order p, i.e. x a x⁻¹ = b + O{p+1} for some x, found by repeated use of Algorithm 7 of the book, conjugacy_step (one order at a time, free parameters set to 0). For a = Ẽ, the underlying one-step method of a general linear method, and b = E, this is the order of the method (with a suitable starting method).

The test is exact: use rational (or other exact) coefficients.

Book: Section 6.6 ("Test for conjugacy").

BSeriesBook.partitioned_form — Function
partitioned_form(glm) -> (glm′, Q)

An equivalent method in the partitioned form (6.6 a), with inputs ỹ = Q⁻¹ y: A′ = A, U′ = U Q, B′ = Q⁻¹ B, V′ = Q⁻¹ V Q. The first column of Q is the preconsistency vector u (V u = u, U u = 𝟏); the others span the range of V - I, the invariant subspace for the other eigenvalues of V. The first component of ỹ is wᵀ y, w the left eigenvector of V for the eigenvalue 1 with wᵀu = 1. Requires 1 to be a simple eigenvalue of V.

Book: Section 6.6, (6.6 a).

BSeriesBook.underlying_one_step — Function
underlying_one_step(glm, T) -> (; E, S, u, Q, xi, eta, etaD)

The underlying one-step method of glm and the starting method that goes with it, to the order of T, such that M ∘ S = S ∘ Ẽ:

  • E::CentralBSeries: Ẽ, the B-series of the underlying one-step method;
  • S::Vector{GeneralBSeries}: the starting method in the original input basis, one B-series per input, S[i][∅] = u[i]; its principal part wᵀS is the identity;
  • u: the preconsistency vector, Q: the change of basis to the partitioned form, inputs ỹ = Q⁻¹ y;
  • xi[n] = ξ(t_n) ∈ ℝ^{r-1}, the non-principal part of the starting method of the partitioned form (ξ(∅) = 0);
  • eta[n] = η(tn), etaD[n] = (ηD)(tn) ∈ ℝ^s, the stages and stage derivatives.

A method that is not in the partitioned form (6.6 a) is first transformed with partitioned_form.

Book: Section 6.6, recursion (6.6 d) and Table 18.

Standard numbering

The book numbers the rooted trees by Algorithm 3 ("Generate trees", Section 2.5). Every tree except t₁ = τ is the β-product tₙ = t_{L[n]} ∘ t_{R[n]}: the tree t_{R[n]} is grafted onto the root of t_{L[n]}, and R[n] ≤ R[L[n]] makes the decomposition unique. Within each order the trees are numbered in the order in which the algorithm produces them. In the package, a tree is its standard number n.

The tables on this page are generated from the package when the documentation is built (Trees, generate_trees). The drawings have the root at the bottom, as in the book.

Here σ(t) is the symmetry, t! the tree factorial (density), α(t) = |t|!/(σ(t) t!) the number of essentially different labellings and β(t) = |t|!/σ(t) (Book, Section 2.5).

Larger tables are obtained the same way, e.g. Trees(10) has 1205 trees. The level sequence of a tree (level_sequence) identifies it in RootedTrees.jl.

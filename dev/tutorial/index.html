Tutorial

This page is a guided tour of the package. Every code block is run when the documentation is built, so the output shown is the output of the current version.

using BSeriesBook

Trees (Chapter 2)

Trees(p) builds all rooted trees up to order p in the book's standard numbering (Algorithm 3 of the book), together with the tree functions (Algorithm 4). Almost every other function takes this object as an argument.

T = Trees(6)
Trees: 37 trees up to order 6

A tree is a Tree: T[n] is the tree with standard number n. It is shown with its number and its B⁺ form:

t = T[17]
t17 = [[[[τ]]]]

Tree functions take the tree, not a number:

[(t, order(t), symmetry(t), factorial(t)) for t in T if order(t) <= 4]
8-element Vector{Tuple{Tree, Int64, Int64, Int64}}:
 (t1 = τ, 1, 1, 1)
 (t2 = [τ], 2, 1, 2)
 (t3 = [τ²], 3, 2, 3)
 (t4 = [[τ]], 3, 1, 6)
 (t5 = [τ³], 4, 6, 4)
 (t6 = [τ[τ]], 4, 1, 8)
 (t7 = [[τ²]], 4, 2, 12)
 (t8 = [[[τ]]], 4, 1, 24)

Children, B⁺ of a forest, level sequence and the standard number:

children(T[6]), bplus(T, [T[1], T[2]]), level_sequence(T[6]), number(T[6])
(Tree[t1 = τ, t2 = [τ]], t6 = [τ[τ]], [1, 2, 3, 2], 6)

The β-product s ∘ t (graft t onto the root of s) is a table lookup:

beta_product(T[2], T[1])       # [τ] ∘ τ = [τ²]
t3 = [τ²]

B-series (Chapter 3)

A B-series is a vector over the standard numbering, a[n] = a(tₙ), whose type records the value on the empty tree, following the sets 𝖡*, 𝖡 and 𝖡⁰ of the book (see Conventions). The exact solution E(t) = 1/t! is a central B-series:

E = exact_solution(T)

The type of a linear combination follows from a(∅): the difference of two central series lies in 𝖡⁰, a sum of two central series in 𝖡*.

a = bseries(kutta4(), T)
typeof(a - E), typeof(a + E), (a + E)[empty_tree]
(VectorFieldBSeries{Rational{BigInt}}, GeneralBSeries{Rational{BigInt}}, 2//1)

Composition

compose(a, b), or a * b, is the book's product ab: first a, then b. The first factor must be central. Two half steps of the exact flow give one full step:

half = rescale(E, 1//2)          # E^(1/2)(t) = 2^-|t| / t!
half * half == E
true

The B-group: inverse, identity and powers.

a * inv(a) == one(a), a^3 == a * a * a, a^-1 == inverse(a)
(true, true, true)

The product is also defined when the second factor is not central; it has the type of the second factor:

g = GeneralBSeries(t -> 1//number(t), T, 2)
typeof(a * g), (a * g)[empty_tree]
(GeneralBSeries{Rational{Int64}}, 2//1)

Algorithm 6 gives the efficient representation λ̂ used in the book to evaluate compositions:

The map slope and implicit stages

slope(y) is the series yD of hf(B_h(y)y₀); for the identity it is D itself:

D = slope(identity_series(T))
coefficients(D)[1:4]
4-element Vector{Rational{BigInt}}:
 1
 0
 0
 0

slope(y, aii) solves the implicit relation of a diagonally implicit stage, dw = wD with w = y + aii·dw. With y the identity and aii = 1 the stage w is the implicit Euler method:

w = identity_series(T) + slope(identity_series(T), 1)
w == bseries(RungeKuttaMethod(fill(1//1, 1, 1), [1//1]), T)
true

A diagonally implicit method stage by stage, Fᵢ = slope(yᵢ, aᵢᵢ) with yᵢ = 1 + Σ_{j<i} aᵢⱼ Fⱼ:

A = [1//3 0 0; 1//2 1//4 0; -1//5 2//3 1//2]; b = [1//4, 1//2, 1//4]
id = identity_series(T)
F = VectorFieldBSeries[]
for i in 1:3
    y = id + sum((A[i, j] * F[j] for j in 1:i-1); init = zero(id))
    push!(F, slope(y, A[i, i]))
end
id + sum(b[i] * F[i] for i in 1:3) == bseries(RungeKuttaMethod(A, b), T)
true

Modified equation and modifying integrator

The modified vector field b ∈ 𝖡⁰ with b ⋆ E = a: the exact flow of y' = h⁻¹ B_h(b)(y) reproduces the method. For the explicit Euler method,

modified_equation(euler(), Trees(4))
VectorFieldBSeries{Rational{BigInt}} to order 4 (8 trees)
    ∅        0//1
 1  τ        1//1
 2  [τ]      -1//2
 3  [τ²]     1//6
 4  [[τ]]    1//3
 5  [τ³]     0//1
 6  [τ[τ]]   -1//12
 7  [[τ²]]   -1//6
 8  [[[τ]]]  -1//4

i.e. f − (h/2) f′f + h² ( f″(f,f)/12 + f′f′f/3 ) + …. For the classical fourth-order method the first nonzero correction appears at order 5:

T7 = Trees(7)
b = modified_equation(kutta4(), T7)
t = first(t for t in T7 if order(t) > 1 && b[t] != 0)
order(t)
5

The modifying integrator (b ⋆ a = E) and the substitution law itself:

T4 = Trees(4)
m = modifying_integrator(euler(), T4)
substitute(m, bseries(euler(), T4)) == exact_solution(T4)
true

Conjugacy (Algorithm 7)

Two central B-series a and b are conjugate to order p if x a x⁻¹ = b + O(h^{p+1}) for some x. conjugate_order applies Algorithm 7 (conjugacy_step) order by order. Conjugating the exact solution with any x gives a series that is conjugate to E to every order computed (here 6), although it differs from E already at order 3:

T = Trees(6); E = exact_solution(T)
x = CentralBSeries(t -> order(t) == 2 ? 1//5 : 0//1, T)
a = inv(x) * E * x
first_difference = order(first(t for t in T if a[t] != E[t]))
first_difference, conjugate_order(a, E)
(3, 6)

The next page applies this to general linear methods.

Working together with BSeries.jl

A B-series of BSeriesBook.jl can be converted to a TruncatedBSeries of BSeries.jl via level sequences, for example to use functionality that only BSeries.jl offers:

using BSeriesBook
import BSeries, RootedTrees

T = Trees(5)
a = bseries(kutta4(), T)

s = BSeries.TruncatedBSeries{RootedTrees.RootedTree{Int, Vector{Int}},
                             eltype(a)}()
s[RootedTrees.rootedtree(Int[])] = a[empty_tree]
for t in T
    s[RootedTrees.rootedtree(level_sequence(t))] = a[t]
end

BSeries.order_of_accuracy(s)   # 4, as order_of_accuracy(kutta4(), T)

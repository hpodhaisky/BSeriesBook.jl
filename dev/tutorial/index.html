Trees (Chapter 2)

Trees(p) builds all rooted trees up to order p in the book's standard numbering (Algorithm 3 of the book), together with the tree functions (Algorithm 4). Almost every other function takes this object as an argument.

T = Trees(6)
Trees: 37 trees up to order 6

A tree is its standard number n. Its B⁺ form, children, level sequence and tree functions:

[(n, bracket(T, n), order(T, n), σ(T, n), γ(T, n)) for n in 1:9]

 (4, "[[τ]]", 3, 1, 6)

The β-product t_ℓ ∘ t_r (graft t_r onto the root of t_ℓ) is a table lookup:

B-series and composition (Chapter 3)

A B-series is a vector over the standard numbering, a[n] = a(tₙ), with a(∅) = 1 implied. The exact solution is E(t) = 1/t!:

E = exact_solution(T)
E[1:8]
8-element Vector{Rational{BigInt}}:
  1
 1//2
 1//3
 1//6
 1//4
 1//8
 1//12
 1//24

compose(a, b, T) is the book's product ab: first a, then b. Two half steps of the exact flow give one full step:

half = [E[n] / 2^order(T, n) for n in 1:length(T)]
compose(half, half, T) == E
true

The inverse in the B-group:

a = [1 // (n + 1) for n in 1:length(T)]
compose(a, inverse(a, T), T) == identity_series(T)
true

Algorithm 6 gives the efficient representation λ̂ used in the book to evaluate compositions:

λ̂ = lambda_hat(T, a, 4)

Modified equation and modifying integrator

The modified vector field b with b ⋆ E = a: the exact flow of y' = h⁻¹ B_h(b)(y) reproduces the method. For the explicit Euler method,

modified_equation(euler(), Trees(4))'
1×8 adjoint(::Vector{Rational{BigInt}}) with eltype Rational{BigInt}:
 1  -1//2  1//6  1//3  0  -1//12  -1//6  -1//4

i.e. f − (h/2) f′f + h² ( f″(f,f)/12 + f′f′f/3 ) + …. For the classical fourth-order method the first nonzero correction appears at order 5:

T7 = Trees(7)
b = modified_equation(kutta4(), T7)
n = findfirst(!iszero, b[2:end]) + 1
order(T7, n)
5

The modifying integrator (b ⋆ a = E) and the substitution law itself:

m = modifying_integrator(euler(), Trees(4))
substitute(m, elementary_weights(euler(), Trees(4)), Trees(4)) ==
    exact_solution(Trees(4))
true

Conjugacy (Algorithm 7)

Two central B-series a and b are conjugate to order p if x a x⁻¹ = b + O(h^{p+1}) for some x. conjugate_order applies Algorithm 7 (conjugacy_step) order by order. Conjugating the exact solution with any x gives a series that is conjugate to E to every order computed (here 6), although it differs from E already at order 3:

T = Trees(6); E = exact_solution(T)
x = [order(T, n) == 2 ? 1//5 : 0//1 for n in 1:length(T)]
a = compose(compose(inverse(x, T), E, T), x, T)
first_difference = order(T, findfirst(n -> a[n] != E[n], 1:length(T)))
first_difference, conjugate_order(a, E, T)
(3, 6)

The next page applies this to general linear methods.

Working together with BSeries.jl

A B-series of BSeriesBook.jl can be converted to a TruncatedBSeries of BSeries.jl via level sequences, for example to use functionality that only BSeries.jl offers:

using BSeriesBook
import BSeries, RootedTrees

T = Trees(5)
a = elementary_weights(kutta4(), T)

s = BSeries.TruncatedBSeries{RootedTrees.RootedTree{Int, Vector{Int}},
                             eltype(a)}()
s[RootedTrees.rootedtree(Int[])] = one(eltype(a))
for n in 1:length(T)
    s[RootedTrees.rootedtree(level_sequence(T, n))] = a[n]
end

BSeries.order_of_accuracy(s)   # 4, as order_of_accuracy(kutta4(), T)
